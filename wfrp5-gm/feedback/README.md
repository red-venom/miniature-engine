# Feedback kit: finding out how the GM really performs in the app

Use these to find out how the GM behaves in the real Claude app. Testing so far used a simulation.

## Files

| File | Use it |
|---|---|
| `1_GM_DIAGNOSTIC.md` | In a **new chat** inside the project, before or between campaigns. Tests what the GM can see, its dice tool, rules knowledge and instructions. About 3 replies. |
| `2_GM_SESSION_DEBRIEF.md` | At the **end of a real play session**, in the **same chat**. The GM audits its own play. About 2 replies. |
| `3_ANSWER_KEY_DO_NOT_PASTE.md` | Don't paste this into the GM chat. The designer uses it to mark the diagnostic. |

## How to use them

1. Open the file on your phone and copy everything below the line `---`.
2. Paste it into the chat as one message.
3. When the GM writes `READY FOR PART …`, type `next`.
4. Copy all the GM's replies, including the JSON block at the end.
5. Paste them back to the designer (the Claude Code session that built these files).
6. Run the diagnostic once now. Run the debrief after your first two or three real sessions.

## Tips

- Don't paste the debrief into a chat with no game in it: there's nothing for it to audit.
- If the GM's reply is cut off, type `continue`.
- Diagnostic chats leave nothing behind, so don't save their output into the project.
